# Мой намаз

Нативное Android-приложение на русском языке для мусульман:

- расписание молитв с локальным расчетом по координатам;
- системные напоминания о намазе;
- счетчики зикра без регистрации и облака;
- раздел Рамадана с временем сухура и ифтара;
- все данные сохраняются только на устройстве.
