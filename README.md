# Мой намаз

Нативное Android-приложение на русском языке для мусульман:

- расписание молитв с локальным расчетом по координатам;
- системные напоминания о намазе;
- счетчики зикра без регистрации и облака;
- раздел Рамадана с временем сухура и ифтара;
- все данные сохраняются только на устройстве.

## Как открыть

1. Откройте папку `MuslimCompanion` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на эмуляторе или телефоне Android.

## Настройка

По умолчанию указаны координаты Москвы. На экране «Молитвы» можно ввести широту и долготу своего города, после чего расписание и напоминания пересчитаются.

Расчет времени молитв и даты хиджри является приближенным. Для религиозно значимых решений сверяйтесь с расписанием местной мечети.
